# 交付产物 recipe

门 3 每次渲染**默认产出三类**，都落交付文件夹。规范源：`做内容/_运营文档/视频成片流水线-模板.md`。

## 交付文件夹 + 命名

```
~/Movies/<系列>/<视频代号>/
  <视频代号>-成片.mp4      合成整片（compose_dual OUT_DIR 指到这里，产物改名）
  <视频代号>-broll.mov     可选 alpha 层
  <视频代号>-标题层.png     透明标题图层（见下）
  <视频代号>-时间轴.txt     章节时间戳（见下）
```

- `<系列>` = `AI` / `拉美` / `出海` …，和项目工作文件夹同名。
- `<视频代号>` = 工作文件夹名（中文可读名，不罗马化，如 `SpaceX收购Cursor`）。
- compose_dual 默认输出 `整片.mp4` / `broll层.mov`；交付时 `mv` 成 `<视频代号>-成片.mp4` / `<视频代号>-broll.mov`，或直接把 `OUT_DIR` 设成交付文件夹后重命名。

## ① 标题透明图层（3:4，一图两用）

**为 3:4 封面设计的透明 PNG**：叠视频顶部区 + 当封面标题层。复用 doc-to-slides 封面模板，**不用 opener 动画卡**（除非该条明确要 4.5s 动画片头）。

规格：
- 画布 **1080×1440**，透明背景
- 大标题 `--ts` **124px**（短句堆叠可用 `.big` ×1.3 ≈ 161px），Noto Serif SC 900
- 顶部对齐，遵守 9:16 三铁律 + 安全区（CONVENTIONS 第三节）

做法（doc-to-slides cover 模板）：
1. 写最小 manifest（一张 cover slide）：主题 + `title_size: 124` + 标题行（视频标题，可标 `.accent` 高亮词）。
2. **把 cover 背景改透明**——去掉主题的米底填充（`.cover`/`.slide` 不铺不透明底色即可）。
   render.py 已带 `--default-background-color=00000000`，元素不铺底 → 直接得透明 PNG，无需额外抠图。
3. 渲染：
   ```bash
   python ~/.claude/skills/doc-to-slides/render.py <manifest>.yaml --only 01
   mv <out>/01-cover.png ~/Movies/<系列>/<视频代号>/<视频代号>-标题层.png
   ```
4. 同一张 PNG 复用给 3:4 封面（叠在封面底图上），保证封面和成片标题长一样。

## ② 章节时间轴（所有视频默认出）

从 cue plan（门 1 表）+ whisper 转写时间码推导。

- **粗颗粒**：约 1 点 / 30–40s。2 分钟片子 3–4 点，别切碎。
- 取点原则：开场钩子固定 `00:00`；每个内容段 / 大 cutaway 起点一个点；结尾 CTA 一个点。
- 格式（B站 / YouTube 简介可直接贴）：
  ```
  00:00 开场钩子
  00:35 第一点
  01:10 第二点
  01:45 收尾 + CTA
  ```
- 写文件：
  ```bash
  cat > ~/Movies/<系列>/<视频代号>/<视频代号>-时间轴.txt <<'EOF'
  00:00 开场钩子
  …
  EOF
  ```
- 同步：把这段文本回填进 `内容管理/成片文案库.xlsx` 的「时间轴」列（见流水线模板 §4）。
