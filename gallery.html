所有 9 个模板按 6 个用户概念组织。每张卡 iframe 实时渲染对应模板的初始帧 / 简化预览。 点 ↻ 重播 重新触发动画。

6 个核心概念

  1. ① 标题卡 · 4.5s 透明叠层片头（黄字衬线大标题）
  2. ② 重点词弹出 · 1-2s 单词强调（chyron 黄胶囊 / chyron_underline 编辑感）
  3. ③ 列举 · ≤4 项并列，stagger reveal
  4. ④ 全屏数据卡 · 不透明 cutaway，每张深度讲一件事
  5. ⑤ 5+ 项逐个介绍 · 顶部安全位单卡轮播 + 末尾 recap
  6. ⑥ 装饰冲击 · 群体 emoji 叠层（特殊场景）
①

标题卡 / opener

4.5s · 透明 alpha · 0s 视频起始

标题卡叠在 talking head 顶部 1/3，永远在视频 0s。透明背景 + 黄色加粗衬线大标题 + 白色斜体副标题，弹性入场 + 呼吸 + 结尾淡出，通用 9:16 口播片头。

yellow · 黄字标题卡

opener/yellow.html
透明背景 + 黄色加粗衬线两行大标题（#ffd12e）+ 白色斜体副标题 + 顶部方块 logo（可替换/删除）。通用 9:16 口播片头。
②

重点词弹出 / chyron

1-2s · 透明叠层 · 顶部安全位

在口播某个瞬间弹出 1-2 秒文字，强调一个词或一个数据。两种视觉：黄胶囊（强冲击）/ 米卡下划线（编辑感）。

chyron · 黄胶囊

animator/chyron/chyron.html
黄底 + 4° skew + 130px 英文 / 96px 长中文 + power3.out pop 弹入。强调点、术语、特质名。

chyron_underline · 下划线

animator/chyron/chyron_underline.html
半透米卡 + 关键词下黄色下划线 wipe-in。编辑/刊物感，适合长文字、不抢镜的标注。
③

列举 / listicle

≤4 项 · 全屏 · 3-5s

口播"1, 2, 3 列举"节奏，每项就一个 label + 一句话副标。≤4 项才不挤；5+ 用概念 ⑤。

scene_listicle

animator/cutaway/scene_listicle.html
半透 cream 卡 + 编号 1-4 逐行 stagger reveal。一次性占位，无叠帧风险。
④

全屏数据卡 / cutaway

不透明 · 覆盖 talking head · 每张深度讲一件事

切到全屏卡片展示一个数据 / 对比 / 抽象概念。每张卡深度讲一件事（≠ 列举的"短而平"）。

scene_blank

animator/cutaway/scene_blank.html
空白 cutaway 基底：caption fade-in + 自由内容区。最常用作"数据 / 对比 / 金句"卡的起点。
⑤

5+ 项逐个介绍 / progressive top card

≥5 项 · 顶部安全位轮播 · 末尾全屏 recap

口播逐个讲 5+ 项（景点 / 类型 / 步骤）。顶部小卡轮播显示当前讲的那个 + 进度条 + 末尾 recap。 主舞台留给 talking head，不打断节奏。

scene_progressive_top_card

animator/cutaway/scene_progressive_top_card.html
顶部 day-strip 进度条 + 主舞台单卡切换（opacity 0↔1）+ 末尾全屏 recap。适合时间轴、地点列表、决策矩阵。
⑥

装饰冲击 / burst emoji

透明叠层 · 1-3s · 无文字内容

"X 密度高 / 满地都是" 的视觉冲击：群体 emoji 啪啪啪落下来。装饰性叠层，不承担说明任务。

scene_burst_emoji

animator/cutaway/scene_burst_emoji.html
透明背景 + 群体 emoji + drop-shadow + gravity fall。y ∈ [660, 1500] 避开 safe zone。
